# PythonRuntime

### Python Standalone Builds
This project produces standalone, redistributable builds of Python.

---

## macOS

| macOS Version | Architecture | Python Versions Available |
|---|---|---|
| macos26 | arm64 | 3.14 (all), 3.13 (all), 3.12 (all), 3.11 (all), 3.10 (all), 3.9 (≤ 3.9.1), 3.8 (≤ 3.8.10) |
| macos15 | arm64 | 3.14 (all), 3.13 (all), 3.12 (all), 3.11 (all), 3.10 (all), 3.9 (≤ 3.9.1), 3.8 (≤ 3.8.10) |
| macos14 | arm64 | 3.14 (all), 3.13 (all), 3.12 (all), 3.11 (all), 3.10 (all), 3.9 (≤ 3.9.1), 3.8 (≤ 3.8.10) |

## Amazon Linux 2023 (AL2023)

| OS | Architecture | Python Versions Available |
|---|---|---|
| AL2023 | x86-64 | 3.14 (all), 3.13 (all), 3.12 (all), 3.11 (all), 3.10 (all), 3.9 (all), 3.8 (all), 3.7 (≤ 3.7.6) |
| AL2023 | aarch64 | 3.14 (all), 3.13 (all) |

## Amazon Linux 2 (AL2)

### Notes
- **3.15**: none yet (all platforms)
- **(all)** = all patch versions available for that minor release
- **(≤ x.y.z)** = available up to and including that patch release
